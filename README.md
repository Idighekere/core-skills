## How to navigate

- **New here?** Start at [00 - Start Here](00-Start%20Here.md).
- **Problems** live in `01-DSA/04-Problems/` — each links to the pattern(s) and data structure(s) it uses.
- **Every data structure, pattern, and concept note** ends with a "Related problems" list pointing back at the journal.

## Conventions

- Code is embedded as fenced code blocks next to the explanation — solutions are written and tested on LeetCode-style platforms, then copied here.
- Metadata is kept in YAML frontmatter (`difficulty`, `status`, `tags:`) using format `topic/...` and `pattern/...`.
- Datasets are **not** committed; notebooks load data at runtime (Colab/URLs). See `02-Machine Learning/01-Concepts/`.
