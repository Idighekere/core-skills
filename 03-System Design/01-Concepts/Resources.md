# Resources

Curated study trail for system design. **Links only** — run through these, then write your own notes in this vault so the knowledge becomes yours.

## Books / long-form
- **System Design Interview — Alex Xu (vol 1 & 2)**: the closest thing to a syllabus. Work the first few chapters step-by-step *while* writing your own notes.
- **Designing Data-Intensive Applications — Martin Kleppmann**: the building blocks (replication, partitioning, consistency) with the rigor underneath the interview gloss.

## Canonical engineering write-ups
- [How Discord stores billions of messages](https://discord.com/blog/how-discord-stores-billions-of-messages) — clever Cassandra sharding.
- [Scaling Shopify](https://shopify.engineering/evolving-shopify-webhooks-architecture) / [Stripe's design](https://stripe.com/blog) case studies — read 2–3 per month, summarize one paragraph each here.
- [Google SRE book — chapters on reliability & capacity](https://sre.google/sre-book/table-of-contents/).

## Practice
- Official mock interviews / peer panels (interviewing.io, Pramp) — one mock = ten hours of reading.
- Re-implement two designs a week using the [playbook](How%20to%20Approach%20a%20System%20Design%20Question.md): URL shortener, then a chat system, then a feed.
