## Method

Every design note answers four questions:

1. **What are we building and for whom?** (scope)
2. **What's the rough shape of the traffic?** (estimates)
3. **Which components go on the whiteboard?** (architecture)
4. **Where will it break, and what do we zoom into?** (deep dive)
